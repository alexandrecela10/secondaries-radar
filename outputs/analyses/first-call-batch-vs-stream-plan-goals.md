# Goals: batch vs stream spike

**Passing bar:** all criteria pass.

1. Both paths produce an alerts table from the same replayed input.
2. The alert diff between paths is empty, or every difference is explained in writing.
3. Every row of the Measurements table has a measured value.
4. A decision file exists at `outputs/decisions/first-call-batch-vs-stream.md` and cites the measured values.
5. The PM explains steps 1 to 8 without notes in a quiz, with 4 or more correct out of 5.
